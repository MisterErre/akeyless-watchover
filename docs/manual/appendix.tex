\chapter{Guard messages}\label{app:guards}
Preconditions that stop the plan before anything reaches Akeyless (\texttt{terraform\_data.model\_guards}).
{\small
\begin{longtable}{@{}>{\raggedright\arraybackslash}p{0.4\linewidth}>{\raggedright\arraybackslash}p{0.56\linewidth}@{}}
\toprule
\textbf{Message starts with} & \textbf{Fix} \\ \midrule\endhead
Duplicate role name & keep the role in one \texttt{roles/*.yaml} file \\
Object names must be absolute & leading \texttt{/}, no trailing \texttt{/} \\
Role / Auth method names must start with & follow \texttt{var.naming}, or set the prefix to \texttt{""} \\
Unknown auth method type & use a modelled type; others via \texttt{export --hcl} \\
Unsupported rule type & item-, target-, role-, auth-method-, sra-rule (\texttt{ara-rule} needs \texttt{allow\_ara\_rules}) \\
Invalid capability for the rule type & use the capabilities listed in the message \\
A deny rule must contain only 'deny' & split deny and allow into two rules \\
approval\_authority cannot be combined & approvers in a separate rule or role \\
Root-scope rule & narrow the path, or \texttt{allow\_root\_scope: true} with a reason \\
Invalid management-plane value & see \texttt{docs/model-reference.md} \\
Association references an auth method that is not in & model it, or \texttt{allow\_external\_auth\_methods: true} \\
Auth method has force\_sub\_claims = true & add \texttt{sub\_claims} to every association \\
PKI issuer: \ldots & one of signer key / CA target; \texttt{auto\_renew} needs \texttt{destination\_path}; CRL/OCSP/ACME/public CA need \texttt{gw\_cluster\_url} \\
custom\_fields.object\_type & STATIC\_SECRET, DYNAMIC\_SECRET or ROTATED\_SECRET \\
event\_forwarders: type must be / runner\_type periodic / slack and teams need url\_var / of type teams require & valid type and events; \texttt{every} for periodic; \texttt{url\_var}; teams needs gateway sources and runner -- \texttt{forwarder} checks all of these \\
model/gateway.yaml defines gateway objects & set \texttt{gateway\_api} \\
gateway allowed\_access / log\_forwarding.type & valid permission; exactly one of auth\_method/access\_id; syslog or splunk \\
\bottomrule
\end{longtable}}
