\section{Get the kit}
\begin{lstlisting}
git clone https://github.com/MisterErre/akeyless-watchover.git
cd akeyless-watchover
python3 -m pip install pyyaml pytest      # add --user or a virtualenv as you prefer
scripts/watchover version
scripts/watchover test --tool tofu        # or --tool terraform; everything must pass
\end{lstlisting}

\section{Install the skill for your AI agent}
The skill is agent- and model-neutral. Build it once (CI also attaches the packages to every run):
\begin{lstlisting}
scripts/watchover build-skill     # dist/akeyless-watchover/ (+ .zip) and dist/prompt-pack/ (+ .zip)
\end{lstlisting}
Then pick the way your agent supports -- Chapter~\ref{doc-agents} has the details for each agent:
\begin{description}[style=nextline,leftmargin=1.5em]
\item[Agents that support Agent Skills] (Claude Code, OpenAI Codex, GitHub Copilot, Cursor, Gemini CLI, \ldots)
\begin{lstlisting}
scripts/watchover install-skill --agent <claude|codex|copilot|cursor|gemini|agents> \
    --project ../akeyless-governance          # or --scope user
\end{lstlisting}
  In apps with an upload screen (for example the Claude apps: \textbf{Customize > Skills}), upload
  \texttt{dist/akeyless-watchover.zip}.
\item[MCP clients] connect \texttt{scripts/watchover\_mcp.py} (tools, docs and the skill commands as prompts).
\item[Chat products and model APIs without either] use the prompt pack: \texttt{system-prompt.md} (or
  the short version) as instructions and \texttt{knowledge/} as uploaded files.
\end{description}
Check the installation by asking the agent for \texttt{akeyless-watchover help}.

\section{Create your governance repository}
The kit is a template: copy it into the repository that will own your Akeyless configuration.
\begin{enumerate}
\item Create an (internal or private) repository, e.g.\ \texttt{akeyless-governance}.
\item Copy \texttt{terraform/}, \texttt{bootstrap/}, \texttt{scripts/} and the CI template for your
  platform (\texttt{ci/github/akeyless-governance.yml} to \texttt{.github/workflows/}, or
  \texttt{ci/gitlab/.gitlab-ci.yml} to the root). Copy \texttt{ci/CODEOWNERS.example} to
  \texttt{CODEOWNERS} and adapt the owners.
\item Add a remote state backend to \texttt{terraform/versions.tf} (and a separate one for
  \texttt{bootstrap/}). The state contains secrets: encrypted, versioned, access-restricted
  (Chapter~\ref{doc-pipeline}).
\item Replace the example model in \texttt{terraform/model/} with yours (Chapter~\ref{ch:quickstart}
  shows how), keeping \texttt{access\_expectations.yaml} in step.
\item Run \texttt{scripts/watchover test} and commit.
\end{enumerate}
